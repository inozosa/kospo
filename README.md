# kospo

한국체육산업개발 공공데이터 활용 경진대회 프로젝트.
올림픽공원 주차 혼잡 예측 및 운영 의사결정 지원 시스템.

## 데이터 원칙

- **한국체육산업개발주식회사가 공공데이터포털에 올린 데이터만 사용한다.**
- 원천 데이터(`data/raw/`)는 용량 문제로 저장소에 올리지 않는다. 각자 공공데이터포털에서 받아 `data/raw/`에 넣는다.
- API 인증키는 `.env`에 두고 커밋하지 않는다.
